# JavaScript Fundamentals Learning Project

This repository contains a small collection of JavaScript practice files focused on learning core language concepts. It is organized chapter by chapter and is intended for beginners who want to understand JavaScript fundamentals through simple, runnable examples.

## Project structure

- `01_chapter_JS_Basic/` — introductory examples, including Hello World and basic math
- `02_chapter_JS_Keyword_Idetifier/` — JavaScript engines, keywords, identifiers, and naming rules
- `03_chapter_JS_Literal/` — number, null, undefined, and other literal examples
- `04_chapter_JS_Operator/` — assignment, arithmetic, comparison, logical, conditional, and `typeof` operators
- `05_chapter_JS_Increament_Decreament_Op/` — increment and decrement operators
- `06_chapter_JS_IF_Statement/` — `if`, `else`, and multiple-condition examples
- `07_chapter_JS_SwitchStatement/` — `switch` statements, grouped cases, and practice questions
- `08_chapter_JS_UserInput/` — examples exploring user input in JavaScript and Node.js
- `09_chapter_JS_Loops/` — loop fundamentals, `for` loops, and practice questions
- `10_chapter_JS_WhileLoop/` — `while` loops and practice questions
- `11_chpter_JS_DOWhile/` — `do...while` loops, including nested-loop examples
- `12_chapter_JS_Array/` — creating, accessing, modifying, searching, sorting, and transforming arrays

## Prerequisites

- Node.js installed on your machine
- A terminal or VS Code integrated terminal

## Run examples

From the project root, run an example file with Node.js:

```bash
node 01_chapter_JS_Basic/001_HelloWorld.js
node 01_chapter_JS_Basic/002_Math.js
node 02_chapter_JS_Keyword_Idetifier/06_KW_IND_Rule.js
node 03_chapter_JS_Literal/11_NumberLiternal.js
node 04_chapter_JS_Operator/22_ComparisionOP.js
node 05_chapter_JS_Increament_Decreament_Op/38_IQ.js
node 06_chapter_JS_IF_Statement/46_IF.js
node 07_chapter_JS_SwitchStatement/50_SwitchStatement.js
node 09_chapter_JS_Loops/64_For_Loops.js
node 10_chapter_JS_WhileLoop/70_IO.js
node 11_chpter_JS_DOWhile/76_Nested.js
node 12_chapter_JS_Array/100_Swap.js
```

You can run other examples the same way by replacing the path with the file you want to try. User-input examples may rely on browser APIs or Node.js-specific APIs, so check the individual file for its runtime requirements.

## Topics covered

- JavaScript syntax, variables, and engine behavior
- Keywords, identifiers, and naming rules
- Number, null, undefined, and other literals
- Assignment, arithmetic, comparison, logical, conditional, and type-checking operators
- Increment and decrement operators
- Conditional branching with `if`/`else` and `switch`
- `for`, `while`, and `do...while` loops
- Arrays, including access, modification, searching, sorting, and destructuring
- User-input examples and runtime differences

## Notes

This project is a learning resource and practice space. The examples are intentionally simple so the underlying JavaScript concepts are easy to follow and experiment with.
